# WortWelt — коригувальний аудит після реальних скриншотів (23.10.2026)

## Чому попередні висновки були помилкові
- 100% карток **мають шлях до медіа**, але це не означає 100% придатності цих медіа для викладання.
- Візуальні докази користувача продемонстрували 4 картки, що не пройшли семантичний/естетичний контроль, хоча технічний тест не знайшов помилки.
- Не використовувати особисті характеристики людей на фотографії як критерій якості. Критерії: один однозначний навчальний суб'єкт, центральне кадрування, розбірливість на телефоні, достатнє світло, відсутність зайвих підписів та неправильного мовного контексту.
- Картки з місцевим SVG є **ілюстраціями**, а не фотографіями. Автоматично рахувати їх як «фото» некоректно.

## Фактичні числа після виправлень
- Усього 1174 картки і 47 тем; без порожніх `photo`-полів.
- **897 карток** мають не-SVG медіа (це фотографії та PNG, включно із відносними адресами); **277 карток** мають SVG-ілюстрації.
- Усі 736 іменників мають окремі медіа-посилання, це лише **перевірка унікальності**, а не естетичне схвалення.
- Не можемо стверджувати, що всі 1174 картки візуально перевірені чи якісні. Статус повного ручного огляду: **НЕ завершений**.
- QA перегляд для всіх карток: `/qa-gallery.html` з фільтрами за 47 темами, типом та форматом; кнопками «добре / замінити» й JSON експортом. Зворотний зв'язок локальний; жодне автоматичне маркування не вигадує схвалення.

## Обов'язковий процес для наступних партій
1. Відкрити реальне медіа й перевірити безпосередній об'єкт/дію на картці в 1:1 форматі мобільної гри.
2. Змінювати тільки якщо нове фото справді краще, а не заради 100% показника.
3. Перевірити правильність `de/uk/en`, теми, артикля та джерела прав.
4. Після commit запустити CI, перевірити рендер на production/preview, а не тільки існування URL.
5. Лічильник схвалених карток рахувати **лише після ручного огляду**. Усі інші позначати «не перевірено».
